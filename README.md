# Última Luz

Juego 2D de supervivencia zombie para navegador. Aguanta oleadas en una ciudad en ruinas, recoge experiencia, mejora tus armas y sobrevive a los titanes que aparecen cada cinco oleadas.

![Última Luz](screenshots/desktop-1366-game.png)

## Controles

| Acción | Teclado y ratón | Táctil |
| --- | --- | --- |
| Moverte | `WASD` / flechas | Joystick izquierdo |
| Apuntar y disparar | Ratón (mantén pulsado) | Joystick derecho + disparo automático |
| Impulso | `Shift` / `Espacio` | Botón del rayo |
| Recargar | `R` | Botón de recarga |
| Cambiar arma | `1`–`4` | Botón de cambio |
| Pausa | `Esc` / `P` | Botón de pausa |
| Sonido | `M` | Botón de sonido |

## Características

- Ciudad procedural con edificios, coches, barreras, farolas y barriles en llamas.
- Cuatro armas: pistola, escopeta, subfusil y rifle de precisión.
- Zombis caminantes, corredores, escupidores de ácido, brutos y un titán cada cinco oleadas.
- Mejoras por nivel, botiquines, munición y adrenalina.
- Iluminación dinámica, linterna, lluvia, niebla y sangre persistente.
- Audio sintetizado con WebAudio, sin archivos externos.
- Diseño responsive con controles táctiles y zonas seguras para móviles y tabletas.

## Ejecutar en local

Sirve la carpeta con cualquier servidor estático y abre `index.html`:

```bash
python3 -m http.server 3002
```

No hay dependencias, compilación ni descargas: todo el juego es HTML, CSS y Canvas 2D.
